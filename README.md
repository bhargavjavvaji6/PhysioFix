# PhysioFix Physiotherapy & Rehabilitation — React SPA

Responsive React + Vite landing page based on the supplied `Landing Page Content.pdf`.

## Run locally
1. Install Node.js LTS.
2. Open this folder in VS Code.
3. Run `npm install`
4. Run `npm run dev`
5. Open the localhost address Vite prints in your terminal.
